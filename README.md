# Data Science Full-Time Training by DataScientest


This repository documents the curriculum and projects for a comprehensive 4-month intensive program in Data Science. The program is designed to provide a strong foundation in the key areas of data science, from programming fundamentals to advanced machine learning and MLOps.

## Curriculum Overview

The program was structured into 10 sprints, each focusing on a specific set of skills and concepts:


* **Sprint 1: Python Basics**
    * Fundamentals of Python for Data Science and Exploratory Statistics.

* **Sprint 2: Data Visualization**
    * Creating effective data visualizations using Matplotlib and Seaborn.

* **Sprint 3: Programming Tools**
    * Essentials of Linux, Bash, Git, and GitHub for developers.

* **Sprint 4: Machine Learning 1/4**
    * Core concepts of Classification and Regression models.

* **Sprint 5: Machine Learning 2/4**
    * Methodology, Feature Engineering, Optimization, and Advanced ML techniques.

* **Sprint 6: Machine Learning 3/4**
    * Dimensionality Reduction and Time Series Analysis.

* **Sprint 7: Deep Learning**
    * Computer Vision with OpenCV and building Neural Networks with Keras.

* **Sprint 8: Machine Learning 4/4**
    * Text Mining and model tracking with MLFlow.

* **Sprint 9: Data Engineering**
    * Fundamentals of SQL and building data applications with Streamlit.

* **Sprint 10: MLOps**
    * Basics of Data APIs and containerization with Docker.
